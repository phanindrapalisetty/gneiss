# Homepage

Homepage is the primary dashboard for Gneiss.

## Purpose

Provides a single landing page for:

- Infrastructure
- Media
- Databases
- Monitoring
- Developer tools

## URL

http://192.168.1.7:3000

## Deployment

```bash
docker compose up -d
```

## Logs

```bash
docker compose logs -f
```

## Stop

```bash
docker compose down
```
